2. CREATE — Création de commande
POST /api/v1/orders/create/
Crée la commande, décrémente le stock, calcule le shipping, applique le coupon.
Body
{
    "origin_address": 1,
    "shipping_method": "standard",
    "transport_mode": "road",
    "discount": 0,
    "coupon_code": "",
    "order_lines": [
        {"product": 23, "quantity": 1},
        {"variant": 5, "quantity": 2}
    ]
}
Identique au body du preview. Le front peut envoyer le même payload aux deux endpoints.
Réponse 201
{
    "id": 1,
    "order_number": "76AFA584",
    "origin_address": 1,
    "shipping_method": "standard",
    "transport_mode": "road",
    "discount": "0.00",
    "delivery_cost": "3000.00",
    "total_amount": "289000.00",
    "status": "pending"
}

Champs à afficher
Élément	Champ API
Nom produit	lines[].product_name
Prix unitaire	lines[].unit_price
Quantité	lines[].quantity
Sous-total ligne	lines[].line_total
Boutique	lines[].shop_name
Sous-total	subtotal

Livraison	delivery_cost
Total	total_amount
Délai livraison	shipping.estimated_days
Livraison internationale	shipping.is_international
Transport	shipping.transport_mode
Logique conditionnelle transport_mode
Si is_international == true:
    → Afficher choix: "Mer 🚢" (value: "sea") | "Air ✈️" (value: "air")
    → Par défaut: "Mer"
Sinon:
    → transport_mode = "road" (pas d'affichage, pas de choix)

5. FLUX COMPLET CÔTÉ FRONT
1. Client ajoute des produits au panier
2. Client choisit une adresse de livraison
   → GET /api/v1/addresses/ (pour lister ses adresses)
3. Client choisit transport_mode (si international)
   → GET preview pour savoir si is_international
   → Si is_international: afficher choix Mer/Air
4. Client clique "Voir récapitulatif"
   → POST /orders/preview/ (avec transport_mode sélectionné)
   → Afficher: produits, sous-total, livraison, total
5. Client applique un coupon (optionnel)
   → Ré-POST /orders/preview/ avec coupon_code
   → Le discount se met à jour dans la réponse
6. Client confirme la commande
   → POST /orders/create/ (même body que preview)
   → Rediriger vers page de confirmation avec order_number
7. Client paie
   → POST /orders/{id}/pay/
   → Body: { "payment_method": [1], "first_name": "...", "last_name": "...", "phone_number": "..." }
8. Client suit ses commandes
   → GET /orders/my-orders/
   → GET /orders/{id}/ (détail)
