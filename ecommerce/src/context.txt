Voici comment les données sont renvoyées lors de la récupération des commandes d'un utilisateur.
Endpoint : GET /api/v1/orders/
Le viewset utilise OrderSerializer (sauf pour create qui utilise OrderCreateSerializer). La réponse est une liste paginée avec ces champs par commande :
Champs de base
Champ
id
order_number
customer
customer_name
order_date
Infos livraison
Champ
shipping_first_name
shipping_last_name
shipping_phone_number
shipping_street_address
shipping_city
shipping_state_region
shipping_postal_code
shipping_country
Montants
Champ
delivery_cost
discount
total_amount
Statuts
Champ
status
payment_status
payment_method
payment_method_name
Paiement
Champ
payment_first_name
payment_last_name
payment_phone_number
Coupon
Champ
applied_coupon_code
Produit (aperçu)
Champ
preview_image_url
preview_product_name
Origine
Champ
is_discussed_order
source_type
source_quote_id
Lignes de commande (order_lines)
